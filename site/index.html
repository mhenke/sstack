The four rules.

sstack is structured negative testing: it explores how software behaves outside the happy path, verifies observed behavior against a declared oracle, and turns confirmed failures into permanent regression tests.

Oracle — the expected behavior written down before the attack: error, degradation, retry bound, invariant, rejection — not only crashes. “It crashes” isn’t an expectation; “it raises a validation error naming the field” is. A test that passes against code you just proved broken has pinned the bug, and a pinned bug is worse than no test at all.

Attack assumptions

Every input, state, and dependency an implementation assumes is a surface to probe.

Define the oracle first

Expected behavior goes down before the attack runs. One oracle, one observable outcome; a verdict only counts when real command output backs it.

No claims as evidence

Never accept an agent’s claim. Run the real command, quote the real output. The agent interprets evidence; it does not manufacture it.

Failure → test → fix

Write the regression test (goes red on the bug), apply the minimal fix (turns it green), harden the surfaces already handled correctly.

The four rules in full: docs/ETHOS.md.

The not-happy cases, staged.

One pass, seven stages and a report. Expected behavior goes down before anything runs; a case that could pass two ways is two verdicts wearing one sentence.

1

Discover

Map surfaces and assumed contracts inside the scope you named.

2

Attack

Fourteen lenses fan out, one attacker agent each, running concurrently.

3

Verify

Observed behavior checked against the oracle written before the attack.

4

Minimize

Reduce the failure to the smallest repro that still trips it.

5

Test

Write the regression test. It goes red on the bug.

6

Fix

Apply the minimal change that satisfies the oracle. Green.

7

Learn

Record the failure class in .sstack/learn/ for the next run.

8

Report

Emit findings: one .md and one .json each, evidence replayable.

How it works in detail: docs/ARCHITECTURE.md.

Fourteen lenses, one failure class each.

Each lens is a rubric plus a dedicated attacker agent. Drop a file with the sstack- prefix in your own tree and the next run picks up your custom lens alongside the shipped fourteen.

boundaries

Numeric, size, index, collection, and pagination edges.

malformed

Wrong types, corrupt structures, encodings.

missing

Absent fields, nulls, empty inputs.

ownership

Subject × object × action × context. BOLA/IDOR, field-level read and write, deny-by-default, least privilege, token integrity, cross-tenant, CORS/CSRF.

exceptional-conditions

Fail-open paths, diagnostic leakage, unreleased resources on abort, empty catch blocks, cascading failures.

resource-exhaustion

Pools, rate limits, memory ceilings, payload limits, disk.

state

Stale cached reads, write-through to caller data, partial updates after failure, escaped internal references.

ordering

Out-of-sequence steps, multi-step pipeline bypass, step skipping.

concurrency

Race conditions, parallel access, double-spend, lost updates.

idempotency

Retried mutations, duplicate submissions, Idempotency-Key divergence.

dependency-failure

Upstream timeouts, 5xx, dropped packets, circuit breaker trip, graceful degradation.

contract

Schema drift, undeclared fields, breaking type changes, spec-to-implementation gaps.

agent

Tool schema divergence, unhandled tool errors, prompt injection, context truncation.

security

SQL/command injection, path traversal, JWT token tampering, insecure deserialization.

All fourteen lenses, detail per lens: docs/LENS.md.

Install.

Two halves, equally required: the skills your agent reads, and the attacker agents.

1

Install the skills

npx skills@latest add mhenke/sstack

Registers /sstack in Claude Code. Hosts without slash commands: open the skill directory in your editor and ask for it in your own words.

2

Install the attackers

Paste into your AI CLI or IDE; the agent does the copying:

Copy the agents/*.md files from https://github.com/mhenke/sstack into ~/.agents/ (create it if missing).

For VS Code:

Copy the agents/*.md files from https://github.com/mhenke/sstack into ~/.copilot/agents/ renamed <name>.agent.md.

Manual process

  • Agnostic → ~/.agents/
  • Claude Code → ~/.claude/agents/
  • VS Code → ~/.copilot/agents/ as <name>.agent.md

Only VS Code needs the rename. Full rows: README.

Then run it on a scope (/sstack src/checkout.ts): a file, directory, module, or package.

Nothing else to install. The evidence emitter is stdlib-only (Python, with Node fallback).
